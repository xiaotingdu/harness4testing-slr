# Venue selection for the venue sweep (decided 2026-10-01)

A venue is swept when its call for papers centres on software engineering and covers software testing, and it is
a CORE A*/A conference (portal.core.edu.au, ICORE2026) or an SJR Q1/Q2 journal.
